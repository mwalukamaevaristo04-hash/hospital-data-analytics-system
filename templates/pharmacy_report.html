📈 Report Interpretation

This report provides an overview of the current pharmacy inventory and prescription activities. The stock value represents the estimated value of medicines currently available in the pharmacy, calculated using quantity multiplied by unit price. The prescription summary shows the number of prescriptions that are pending, dispensed, or cancelled. The category table summarizes medicine availability according to medicine category, while the most dispensed table identifies medicines with the highest dispensing quantities.
